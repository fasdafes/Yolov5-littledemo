2，自动anchor匹配和优化

autoAnchor：它使用的是 K-means 聚类 + IoU 距离度量 + Genetic Algorithm（遗传算法）微调

自动IoU评估anchor：
遍历数据集中所有 ground truth box（GT）；
对每个 GT，计算其与所有 anchor 组合（w, h）的 IoU；
找到该 GT 最匹配的 anchor（最大 IoU）；
如果最大 IoU > 阈值（如 0.2），视为“匹配成功”；
统计总共多少 GT 是“被匹配”的 → 得到 BPR；
如果 BPR < 0.98 → anchor 不理想，需要 autoanchor。

（1），首先LocationLoss的计算方式变了，从普通MSE变成了CIoU
	   
	什么是CIoU？
	IoU---------->GIoU------------>DIoU------------------>CIoU
	
				Area（intersection）
	IoU: 重合度 = -----------------------------    （缺点是没有相交的时候返回0）无法造成梯度

	————————————————————————————————————————
							        |  C  - （A∪B）|
	GIoU：Generalized IoU =  IoU   -   -------------------------   （优点是就算没重合也有负数输出）
									| C |
	————————————————————————————————————————

								ρ^2
	DIoU：Distance IoU = 1 - IoU +  ---------------   （有点是弥补了GIoU不关注中心点的缺点）
							         c^2
	ρ^2 = ( x(pred)  - x(gt) )^2  + ( y(pred) - y(gt) )^2
	c^2 = Wc^2   +   Hc^2           Wc,Hc是同时包含预测框和真实框的最小外接矩形的宽和高
	————————————————————————————————————————
								    ρ^2
	CIoU： Complete IoU  =  1 - IoU +  -----------   + αv    
								   c^2

					   4		      w^(gt)			      w^(pred)
	v ：宽高比惩罚项 v =  -----  ( arctan ----------   -   arctan ----------   )^2
					 π^2			h^(gt)		      h^(pred)

						   v
	α ：动态调节因子  α = -------------------
					     1 -  IoU +v
	
	即使 IoU 很高，如果预测框的形状和真实框差异很大（比如一个长条，一个方形），也可能不适合检测
	CIoU 的各部分（IoU + 中心距离 + 宽高比）都是有梯度的、连续的、可导的，因此反向传播稳定。
	加了宽高比后，可以避免模型陷入“只是对齐中心和面积，但形状不对”的局部最优。

（3）boj/cls 损失平衡
	 
	YOLO 主要任务是检测（找框 + 判断有没有物体），而不是分类为主。
	大多数 anchor 是背景，分类损失只对正样本算，obj loss 则影响更广 → 权重要大些。
	分类任务通常较容易，过高权重容易造成不平衡训练
	所以λ(cls)一般只有λ(obj)的一半
